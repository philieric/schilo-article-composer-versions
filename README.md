# Schilo Article Composer — versions publiées

Ce dépôt ne contient que les versions publiées de Schilo Article Composer :

- `latest-version.txt` — le numéro de la dernière version, lu par l'application pour proposer la mise à jour ;
- les **Releases** — l'installateur `SchiloArticleComposer.msi` de chaque version.

Il n'y a pas de code ici. Tout y est déposé automatiquement à chaque publication. Ne rien y mettre à la main, et jamais
rien de secret : ce dépôt est public.
